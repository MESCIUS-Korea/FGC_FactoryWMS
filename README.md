# 공장재고관리 시스템 (FactoryWMS)

**Repository**: MESCIUS-Korea/FGC_factorywms *(실제 저장소 이름으로 수정해주세요)*

제조 공장의 입출고, 재고, LOT, 불량, 유효기간을 한 화면에서 관리하고, 자연어로 질문하면 답변을 받을 수 있는 공장재고관리 시스템입니다. Forguncy(노코드 플랫폼)로 제작되었습니다.

## 주요 기능

- 📦 **입고·출고 등록** — 품목·LOT 단위 입출고 기록
- 📋 **재고현황·LOT 추적** — 실시간 재고 수량과 LOT별 이력 조회
- ⚠️ **불량처리** — 불량 등록 및 품목·LOT별 불량 이력 확인
- 📅 **유효기간알림** — 유효기간 임박 LOT을 자동 감지하고 AI가 브리핑 문장으로 요약
- 💬 **AI 챗봇** — 재고·주문·불량 현황을 자연어로 질문하고 답변받는 헤더 플로팅 챗봇
- 📊 **대시보드** — 전체 재고·불량·유효기간 현황 요약

## 페이지 구성

### 입고·출고 등록
품목과 LOT 단위로 입고·출고 내역을 등록합니다. 등록된 데이터는 재고현황과 LOT 추적의 기준이 됩니다.

### 재고현황·LOT 추적
현재 재고 수량을 품목별로 확인하고, 특정 LOT이 어느 창고에 어떤 상태로 있는지 추적할 수 있습니다.

### 불량처리
품목·LOT를 선택해 불량 내용을 등록하고, **"이력 확인"** 버튼으로 최근 90일 불량 건수와 최근 불량 원인을 즉시 확인할 수 있습니다. 이 조회는 파라미터 설정과 조건문만으로 처리되며, 결과가 명확한 조회이므로 AI를 호출하지 않습니다.

### 유효기간알림
유효기간이 임박한 LOT 목록을 자동으로 걸러 보여주고, **"AI 브리핑"** 버튼을 누르면 여러 건의 임박 현황을 사람이 읽기 좋은 자연어 문장으로 요약해줍니다.

**명령 체인**
```
① 파라미터 설정: alertRows (VW_유효기간알림 조회, 유효기간 ≤ TODAY()+30, 정렬: 유효기간 오름차순)
② 파라미터 설정: alertText = ""
③ 루프(alertRows): alertText에 "- 품명(LOT번호, 창고코드): D-day" 형식으로 한 줄씩 누적
④ AI 도우미 명령: 사용자 프롬프트에 alertText 전달 → briefingRaw
⑤ 파라미터 설정: briefingClean = SUBSTITUTE(briefingRaw, "\n", "")  ← 줄바꿈 이스케이프 제거
⑥ JSON 역직렬화: briefingClean → briefing
⑦ 화면 표시: briefing.headline, briefing.summary, briefing.priority_action
```

시스템 프롬프트에는 "숫자(건수, D-day, 위험도)는 이미 계산되어 주어진 값을 그대로 사용하고 스스로 재계산하지 말 것"과 "JSON은 한 줄로 압축 출력할 것"을 명시합니다.

### AI 챗봇
화면 상단에 항상 떠 있는 플로팅 챗봇으로, 모든 탭에서 동일하게 접근할 수 있습니다. 질문의 의도를 자동으로 분류해 알맞은 데이터를 조회합니다.

```
AI 도우미 명령 → resp(intent, item_name, supplier_name, lot_number, period_days)
  overall_analysis → 집계 + 루프 + 2차 AI 분석
  item_query       → 불량처리 필터링 (품목명, 기간)
  supplier_query    → 공급업체별 불량 조회
  lot_query        → LOT마스터 + 불량처리 조인
  unknown          → "품목명이나 공급업체명, LOT번호로 다시 물어봐 주세요"
```

### 대시보드
전체 재고·불량·유효기간 현황을 한 화면에서 요약해 보여줍니다.

## AI 사용 원칙

이 시스템에서 AI는 아래 기준으로 선택적으로 사용됩니다.

| 유형 | 예시 | 처리 방식 |
|---|---|---|
| 건수 집계, 필터링, 단순 조회 | "최근 90일 불량 건수는?" | 파라미터 설정 + 조건문 (AI 미사용) |
| 여러 건을 종합해 자연어 문장으로 요약 | "이번 주 유효기간 임박 품목을 브리핑해줘" | AI 도우미 명령 |

정확한 조건으로 찾을 수 있는 답은 로직으로 처리해 속도와 정확성을 확보하고, 여러 건을 종합해 설명이 필요한 경우에만 AI를 사용합니다. 그래서 불량처리는 "AI 인사이트"가 아니라 **"이력 확인"**으로, 실제 AI가 관여하는 유효기간알림과 챗봇에만 "AI"라는 이름을 붙였습니다.

## UX 원칙

- AI 호출은 드롭다운 변경 등으로 자동 실행되지 않고, **버튼 클릭 시에만** 이루어집니다.
- 클릭 즉시 로딩 스피너를 표시해 대기 중임을 알립니다.

## 실행 방법

1. [Forguncy 디자이너](https://www.grapecity.com/forguncy) 설치
2. 프로젝트 파일을 디자이너에서 열기
3. 파일 > 옵션 > 응용 프로그램 설정에서 AI 모델(OpenAI 등) 연결 — API 키 직접 등록 필요
4. 유효기간알림 페이지, AI 챗봇의 AI 도우미 명령에서 방금 등록한 모델 선택
5. 미리보기 또는 게시로 실행
