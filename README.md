# 공장재고관리 AI (FactoryWMS AI)

**Repository**: MESCIUS-Korea/FGC_factorywms *(실제 저장소 이름으로 수정해주세요)*

기존 공장재고관리(FactoryWMS) 시스템에 AI 기능을 통합한 데모입니다. 입고·출고, 재고현황·LOT추적 같은 기본 재고관리 기능 위에, **AI 브리핑**과 **AI 챗봇** 기능을 추가했습니다.

## 핵심 설계 원칙

> **정확한 조건으로 찾을 수 있는 것은 로직으로, 여러 건을 종합해 새로운 문장을 짓는 것만 AI로.**

| 유형 | 예시 | 처리 방식 |
|---|---|---|
| 건수 집계, 필터링, 단순 조회 | "최근 90일 불량 건수는?" | 파라미터 설정 + 조건문 (AI 아님) |
| 여러 건을 종합해 자연어 문장으로 요약 | "이번 주 유효기간 임박 품목을 브리핑해줘" | AI 도우미 명령 |

이 원칙에 따라, **"AI"라는 이름은 실제로 AI가 관여하는 기능에만 붙였습니다.** 불량처리 이력 확인은 AI 없이 로직만으로 처리되므로 "AI 인사이트"가 아니라 **"이력 확인"**으로 이름 붙였습니다.

## 페이지 구성

### 기존 기능 (AI 미포함)
- 입고·출고 등록
- 재고현황·LOT추적
- 대시보드
- 로그인

### 1. 불량처리 — 이력 확인 (AI 아님)
품목·LOT를 선택하면 "이력 확인" 버튼으로 최근 90일 불량 건수와 최근 불량 원인을 보여줍니다. 파라미터 설정(집계)과 조건문만으로 구현되어 있으며, AI를 호출하지 않습니다. 버튼 클릭 시에만 조회하도록 만들어, 드롭다운 변경마다 자동 실행되지 않게 했습니다.

### 2. 유효기간알림 — AI 브리핑
유효기간이 임박한 LOT 목록을 AI가 자연어 브리핑 문장으로 요약해주는 기능입니다.

**명령 체인**
```
① 파라미터 설정: alertRows (VW_유효기간알림 조회, 유효기간 ≤ TODAY()+30, 정렬: 유효기간 오름차순)
② 파라미터 설정: alertText = ""
③ 루프(alertRows): alertText에 "- 품명(LOT번호, 창고코드): D-day" 형식으로 한 줄씩 누적
④ AI 도우미 명령: 사용자 프롬프트 = [%AiUserInput%](=alertText) → briefingRaw
⑤ 파라미터 설정: briefingClean = SUBSTITUTE(briefingRaw, "\n", "")  ← 줄바꿈 이스케이프 제거
⑥ JSON 역직렬화: briefingClean → briefing
⑦ 화면 표시: briefing.headline, briefing.summary, briefing.priority_action
```

**시스템 프롬프트 핵심 지시**: 숫자(건수, D-day, 위험도)는 이미 계산되어 주어진 값을 그대로 사용하고 AI가 스스로 재계산하지 않도록 명시. JSON은 들여쓰기·줄바꿈 없이 한 줄로 압축 출력하도록 지시.

### 3. AI 챗봇 (헤더 플로팅 위젯)
전체 화면 헤더에 떠 있는 챗봇으로, 모든 탭에서 동일하게 접근 가능합니다.

**의도 분류 구조**
```
AI 도우미 명령 → resp(intent, item_name, supplier_name, lot_number, period_days)
  overall_analysis → 집계 + 루프 + 2차 AI 분석
  item_query       → 불량처리 필터링 (품목명, 기간)
  supplier_query    → 공급업체별 불량 조회
  lot_query        → LOT마스터 + 불량처리 조인
  unknown          → "품목명이나 공급업체명, LOT번호로 다시 물어봐 주세요"
```

## 느린 AI 호출 UX 원칙

- 드롭다운 변경 등으로 자동 실행되지 않고, **버튼 클릭 시에만** AI를 호출합니다.
- 클릭 즉시 로딩 스피너를 표시해 대기 중임을 알립니다.

## 실행 방법

1. [Forguncy 디자이너](https://www.grapecity.com/forguncy) 설치
2. 프로젝트 파일을 디자이너에서 열기
3. 파일 > 옵션 > 응용 프로그램 설정에서 AI 모델(OpenAI 등) 연결 — API 키 직접 등록 필요
4. 유효기간알림 페이지, AI 챗봇의 AI 도우미 명령에서 방금 등록한 모델 선택
5. 미리보기 또는 게시로 실행
